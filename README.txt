PATH & PETAL — WEBSITE TOKO ONLINE

STRUKTUR FILE
- index.html : halaman utama website
- style.css  : seluruh tampilan website
- script.js  : fungsi keranjang, variasi produk, size guide, dan checkout WhatsApp
- README.txt : petunjuk penggunaan
- LICENSE.txt: lisensi dari arsip sumber

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Pastikan index.html, style.css, dan script.js berada dalam satu folder yang sama.
3. Buka index.html menggunakan browser (Chrome, Edge, atau Firefox).
4. Untuk publikasi, unggah ketiga file utama tersebut ke root repository/hosting statis.

CATATAN
- Website ini merupakan prototipe toko Path & Petal.
- Harga, produk, tautan marketplace, dan informasi kontak mengikuti data pada file sumber.
- Nomor WhatsApp checkout di script.js masih berupa nomor contoh (6280000000000); ganti dengan nomor WhatsApp toko yang aktif sebelum digunakan.
- Foto produk pada file sumber masih berupa blok visual berwarna dan teks nama produk; siapkan foto produk asli jika ingin menampilkannya.
